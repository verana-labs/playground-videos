# Vesta narration, one clip per scene (recommended)

Generate each block below as its **own ElevenLabs generation** (same voice and
settings for all) and save it under the exact filename shown, in
`public/assets/vo/vesta/`. Then delete `public/assets/vo/vesta.mp3` (the
single-track fallback wins if present), run `npm run sync`, and render.

Each clip starts exactly at its scene, so TTS pacing can never drift out of
sync: a clip may run slightly shorter than its scene (fine, silence follows),
it just should not run longer. No break tags needed anywhere. Keep acronyms
plain (KYB, DIDComm, ECS-Badge): spelled-out hyphens make ElevenLabs slow
down on that sentence and rush the next one.

Scene lengths are noted as a budget; speak naturally, the timing takes care
of itself.
